# react-native-island-toast

Dynamic-Island style toasts for React Native: a big icon that morphs into a message pill. Fully customizable.

## Installation


```sh
npm install react-native-island-toast
```


## Usage


```js
import { multiply } from 'react-native-island-toast';

// ...

const result = multiply(3, 7);
```
